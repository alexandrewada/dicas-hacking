# dicas-hacking

Caderno pessoal de pentest autorizado — 1000 notas operacionais.

Não é curso introdutório. Cada nota assume que você já sabe o básico da família e precisa do que muda o jogo: variante, OpSec, falso positivo, detecção, remediação e evidência que sobrevive peer review.

Índice: [indice/README.md](indice/README.md)

Leia o [aviso](DISCLAIMER.md) antes de qualquer coisa.

## O que tem aqui

- Recon → report, passando por web/API, auth, injection, AD, cloud, k8s, mobile, wireless, purple
- Notas base + ângulos (detecção, lab, evidência, path, hardening) quando a técnica pede
- Tom de caderno de engajamento: 1ª pessoa, ROE explícito, sem dump massivo no PDF
